# SafeWebGuard - حارس الويب العائلي 🛡️

الموقع الرسمي لتطبيق **SafeWebGuard (حارس الويب العائلي)** لأجهزة أندرويد.

## 📖 حول المشروع
تطبيق إسلامي مجاني 100% لوجه الله تعالى لحماية البيوت، والأبناء، والشباب من المحتوى الإباحي والمواقع الضارة، مع درع VPN عائلي وخدمة حماية فورية لمنع التراجع والالتفاف.

## 🚀 طريقة الرفع على GitHub و GitHub Pages
جميع ملفات الموقع موجودة مباشرة في المجلد الرئيسي (بدون أي مجلدات فرعية) لتسهيل الرفع:
1. ارفع جميع الملفات مباشرة إلى مستودع (Repository) في حسابك على GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. في قسم **Branch** اختر `main` واضغط **Save**.
4. سيعمل الموقع مباشرة على رابط GitHub Pages الخاص بك!

## 📂 محتويات المجلد:
- `index.html`: الصفحة الرئيسية للموقع.
- `style.css`: ملف التنسيقات والتصميم.
- `app.js`: منطق التفاعل والوضع الليلي/النهاري والأسئلة الشائعة.
- `logo.png`: شعار الموقع والتطبيق.
- `favicon.png`: أيقونة تبويب المتصفح.
- `SafeWebGuard-Family.apk`: ملف التطبيق الجاهز للتنزيل المباشر.
- `.nojekyll`: لتفعيل استضافة GitHub Pages بسلاسة.
